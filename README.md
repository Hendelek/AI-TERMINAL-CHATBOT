# AI Terminal Chatbot

A conversational AI chatbot running in the terminal, built with Python and Groq API.

## Features
- Real-time AI responses
- Conversation history
- Secure API key management via .env

## Technologies
- Python 3.14
- Groq API (llama-3.3-70b)
- python-dotenv

## How to run
1. Clone the repo
2. Install dependencies: `pip install groq python-dotenv`
3. Create `.env` file with your `GROQ_API_KEY`
4. Run: `python chat.py`
